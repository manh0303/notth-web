# Product brief

NOTTH — Nothing unnecessary.

Build the official open-source developer-tool website as a new product. Help developers understand NOTTH, judge whether it fits their project/tool, install it using verified instructions, and continue to official docs.

Primary audience: developers evaluating NOTTH. Secondary audience: returning users seeking setup/docs and contributors seeking GitHub source. These personas are inferred, not research findings.

Owner-confirmed constraints (SRC-001): Astro, TypeScript, CSS, GitHub Pages at https://manh0303.github.io/notth-web/; minimal dark premium identity with subtle violet; real editable Figma; desktop/tablet/mobile; logo motion; requirements/design/UAT approval; feature branch; no auto-merge/release; never change the framework repo from this project.

MVP scope: homepage, differentiated static wordmark, honest feature explanations, Requirements → Design → Code → Test → Review, verified install guide, official docs and GitHub links, responsive/accessibility/SEO, QA/UAT/release evidence.

Non-goals: backend, accounts, database, billing, hosted agent runtime, unverified autopilot claims, advertising, analytics collection, blog, local documentation portal, translations, React, design-system marketplace. Any expansion requires an owner decision.

Approvals: Gate 1 before UI/UX; Gate 2 before production UI completion; Gate 3 before acceptance. Deployment/release and merge also require explicit authorization. No approvals recorded.
